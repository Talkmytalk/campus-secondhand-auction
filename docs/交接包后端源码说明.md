# 后端源码说明

这个目录提供后端源码，供阅读和排查问题使用。直接开发页面或执行接口测试，可以使用交接包根目录已打包的 `campus-auction.jar`。

项目位置：`backend` 文件夹。使用 Java 17 和 Maven；本地文件数据库为 H2，无需另外安装数据库。

在 IDEA 中打开 `backend`，等待 Maven 依赖加载后，运行 `edu.campus.auction.AuctionApplication` 的 main 方法。工作目录设为 `backend`。如遇 `Unable to establish loopback connection`，在该运行配置中加入 VM options：`-Djdk.net.unixdomain.tmpdir=.`。

在 `backend` 目录的终端也可以执行：

```text
mvn test
mvn package
java "-Djdk.net.unixdomain.tmpdir=." -jar target/campus-auction-0.1.0-SNAPSHOT.jar
```

源码构建首次需要下载依赖。项目的 `.mvn` 文件夹提供 Maven 官方仓库配置；若 IDEA 的 Maven 设置没有采用该配置，可以将 User settings file 指向 `.mvn/settings.xml` 后重新加载。

接口、功能范围和小组任务以交接包“文档”目录为准。需要修改接口时先与组长核对，统一更新接口说明，避免页面和后端采用不同的字段。
