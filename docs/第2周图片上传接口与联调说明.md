## 规则

- 每场拍卖最多一张图片，可以无图发布，旧数据继续有效。
- 仅登录的发布者可上传。已有有效出价、到达截止时刻或已经结束时，不允许上传或替换。
- 发布拍卖成功取得id后再上传；上传失败不撤销已发布拍卖，可在规则允许时对同一id重试，不要重复发布。
- 支持实际可解码的JPG/JPEG、PNG，文件名扩展名也须符合要求；不接受SVG、GIF、文本伪装图片或空文件。
- 原文件最多5MiB（5×1024×1024字节）；边长最多4096像素，总像素最多1600万。转换后的PNG也不能超过5MiB。
- 服务端重新编码为PNG，使用固定读取地址，不信任上传文件名或客户端Content-Type。图片存入本地H2数据库，与拍卖数据一起保存；无需单独配置图片文件夹。
- 使用拍卖行锁和事务协调图片变更与出价。谁先获得锁并完成操作决定顺序：出价先完成后，图片修改必须拒绝。

## 上传

`POST /api/auctions/{id}/image`

需要 `Authorization: Bearer token`，请求使用 `multipart/form-data`，字段名 `file`。成功返回200及最新拍卖对象，新增 `imageUrl` 字段，如 `/api/auctions/1/image`。无图片时该字段为null。原JSON发布、出价、付款接口不变。

前端调用示例（已有App.api只适用于JSON，不要用它直接传FormData）：

```javascript
const form = new FormData();
form.append('file', selectedFile);
const response = await fetch(
  window.APP_CONFIG.API_BASE + '/api/auctions/' + auctionId + '/image',
  { method: 'POST', headers: { Authorization: 'Bearer ' + App.getToken() }, body: form }
);
// 不手写Content-Type，浏览器必须自动添加multipart边界。
const result = await response.json();
if (!response.ok) throw new Error(result.message);
const imageSrc = result.imageUrl ? window.APP_CONFIG.API_BASE + result.imageUrl : null;
```

PowerShell可使用curl.exe验证（将id、token和文件路径替换为自己的值）：

```powershell
curl.exe -X POST 'http://127.0.0.1:8080/api/auctions/1/image' -H 'Authorization: Bearer 你的token' -F 'file=@C:/Pictures/lamp.png'
```

## 读取

`GET /api/auctions/{id}/image` 无需登录，返回PNG二进制。不存在图片返回404 JSON错误。带有nosniff和no-store响应头，避免浏览器猜测为可执行内容，以及替换后看到旧缓存。列表和详情返回imageUrl，前端应拼接后端地址显示；对无图和图片读取失败提供占位提示。

## 常见错误

| HTTP状态 | 错误码 | 原因 |
| --- | --- | --- |
| 400 | IMAGE_INVALID | 文件缺失、为空、内容不可解码、格式或扩展名不支持 |
| 400 | IMAGE_DIMENSIONS | 图片边长或总像素超限 |
| 401 | LOGIN_REQUIRED | 未登录或令牌无效 |
| 403 | FORBIDDEN | 当前用户不是卖家 |
| 404 | AUCTION_NOT_FOUND / IMAGE_NOT_FOUND | 拍卖或图片不存在 |
| 409 | IMAGE_LOCKED | 已出价或已到期，不能修改 |
| 413 | IMAGE_TOO_LARGE | 原始文件、转换结果或请求超限 |
| 415 | UNSUPPORTED_MEDIA_TYPE | 上传接口未使用multipart/form-data |
