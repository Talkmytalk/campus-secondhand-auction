## 两位队员先各自启动一次后端

1. **先完整解压**到自己有写入权限的文件夹，再操作文件。
2. 电脑需要 Java 17。可以在终端输入 `java -version` 核对；没有 Java 或启动失败时，反馈完整错误信息。
3. Windows 用户双击 `启动后端.cmd`，保留运行窗口。后端启动可能需要等待几十秒。
4. 浏览器打开 `http://127.0.0.1:8080/api/health`。看到 `"status":"UP"` 即说明后端已启动。
5. 这是接口检查结果，**还没有拍卖网页**。网页由前端同学开发。
6. 第一版没有预置账号，按《接口说明》注册自己的测试账号。可分别注册卖家 A、买家 B、竞拍者 C；同一账号也可以在不同拍卖中担任不同角色。
7. 数据保存在当前文件夹的 `data` 目录。正常停止用运行窗口里的 Ctrl+C；重新启动同一份程序和数据目录后，可以继续使用原账号和数据。

也可以在 JAR 所在文件夹的终端运行：

```text
java "-Djdk.net.unixdomain.tmpdir=." -jar campus-auction.jar
```

如果 8080 已被其他程序使用，先核对是否已经开了一份后端。需要改用 8081 时，可运行：

```text
java "-Djdk.net.unixdomain.tmpdir=." -jar campus-auction.jar --server.port=8081
```

对应的前端连接地址也要改成 8081。macOS / Linux 可以使用同样的 Java 命令，不使用 Windows 启动脚本。

## 当前建议的连接方式

两位队员分别在自己电脑上运行一份后端。前端开发者在同一台电脑运行前端页面和后端服务；测试同学在自己的电脑测试接口。

`127.0.0.1` 表示当前这台电脑。因此每个人使用的是各自的本地数据库，彼此注册的账号和发布的商品不会自动同步。接口示例中的编号和令牌也需要替换成自己实际取得的值。

默认允许页面从 `http://localhost:5173`、`http://127.0.0.1:5173`、`http://localhost:3000`、`http://127.0.0.1:3000` 访问后端。前端采用其他页面地址时，把完整地址反馈给组长，以便核对跨域配置。

第一版后端默认只监听本机，暂未配置跨电脑共享访问。之后进行整组演示时，可以先安排在一台电脑上运行页面和后端。
